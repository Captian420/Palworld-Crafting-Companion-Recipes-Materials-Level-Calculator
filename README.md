# Palworld Crafting Companion

A free browser-based **Palworld crafting recipe and level calculator**.

**Live site:** https://captian420.github.io/Palworld-Crafting-Companion-Recipes-Materials-Level-Calculator/

## What it does

- Set your Palworld player level and show recipes available through that level.
- Browse weapons, armor, Pal gear, structures, production, food, medicine, ammo, materials, and more.
- Show direct crafting recipes.
- Expand intermediate components into a full crafting breakdown.
- Calculate final base-material totals.
- Show where to obtain materials, including farming areas, coordinates, Pal drops, merchants, expeditions, and other documented sources.
- Browse level-gated Technology Tree unlocks.

## GitHub Pages

This repository is prepared for GitHub Pages. To publish:

1. Open **Settings → Pages**.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select **main** and **/(root)**.
4. Click **Save**.

Expected site URL: https://captian420.github.io/Palworld-Crafting-Companion-Recipes-Materials-Level-Calculator/

## Search indexing

After Pages is live, add the site to Google Search Console, submit `https://captian420.github.io/Palworld-Crafting-Companion-Recipes-Materials-Level-Calculator/sitemap.xml`, and request indexing for the homepage.
